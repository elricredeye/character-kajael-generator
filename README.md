# character-kajael-generator
Kajaelのプロフィールとアシュランドでの行動パターンに基づき、時間・場所・服装を決定し、Higgsfield MCPを呼び出して画像・動画を生成します。
OpenClaw / Claude Code 用の Kajael（カジャエル）画像・動画生成スキル (外部MCP連携型) パッケージです。

## インストール方法

1. 本ZIPファイルを解凍し、OpenClaw ワークスペースのスキルフォルダに配置します。

   ```bash
   mkdir -p ~/.openclaw/workspace/skills/character-kajael-generator
   cp -r * ~/.openclaw/workspace/skills/character-kajael-generator/
